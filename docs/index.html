Why use this

  • Print door access logs, temperature alerts, todo lists, daily reports, or shopping lists automatically
  • Works with any $30+ thermal printer that speaks ESC/POS (most receipt printers do)
  • Connects via TCP/IP, USB, Bluetooth, or a serial cable / ESPHome serial proxy
  • Set up as many printers as you need — target them individually or broadcast to all
  • Direct connection to your printers. No cloud, everything stays local

Feature roll

  • Formatted text: bold, underline, alignment, font sizes, UTF-8 with automatic character conversion
  • QR codes, barcodes, and images from URLs, files, camera/image entities, or base64
  • Text effects: boxes, multi-column tables, custom-font and rotated text
  • Paper feed, cut, and buzzer control
  • Paper status sensor — automate on paper low / paper out
  • 35+ printer profiles with automatic feature detection, plus 23 rebadged/clone models as "(compatible)" entries
  • Guided calibration wizard that measures and saves your printer's settings
  • Device page buttons: Feed / Cut / Beep / Sample print
  • Full UI configuration — no YAML required

Quick start

You will need

  • Home Assistant 2026.5 or later (0.4.x of this integration still works on HA 2024.8+)
  • A thermal printer with ESC/POS support — Epson TM series, Star Micronics, Citizen, and most generic 58mm/80mm receipt printers
  • Network: reachable on your LAN (usually port 9100) · USB: plugged into the HA host · Bluetooth: paired on the host · Serial: device path or ESPHome proxy

Install

  1. Open HACS in Home Assistant — this integration is in the default store, no custom repository needed
  2. Search for "ESC/POS Thermal Printer" and install it
  3. Restart Home Assistant

Configure

  1. Go to Settings → Devices & services → Add Integration
  2. Search for "ESC/POS Thermal Printer" and pick your connection type
  3. Select your printer model, or "Generic (no profile)" if it isn't listed
  4. Done — start printing

Epson and Rongta network printers are auto-discovered via DHCP and offered in Settings → Devices & Services. USB printers may be auto-discovered when connected.

Examples

Print a message

service: escpos_printer.print_text
data:
  text: "Hello from Home Assistant!"
  align: center
  cut: partial

Print a QR code

service: escpos_printer.print_qr
data:
  data: "https://www.home-assistant.io"
  size: 8
  align: center
  cut: partial

Print a bordered header

service: escpos_printer.print_box
data:
  text: DAILY REPORT
  style: auto
  padding: 1
  align: center

Prints:

   ┌──────────────────────┐
   │     DAILY REPORT     │
   └──────────────────────┘

Print a receipt-style table

service: escpos_printer.print_table
data:
  rows:
    - ["Item", "Qty", "Price"]
    - ["Coffee", "2", "$6.00"]
    - ["Bagel",  "1", "$3.50"]
  style: single
  header: true
  column_aligns: ["left", "center", "right"]

Prints:

┌──────────┬─────┬───────┐
│ Item     │ Qty │ Price │
├──────────┼─────┼───────┤
│ Coffee   │  2  │ $6.00 │
│ Bagel    │  1  │ $3.50 │
└──────────┴─────┴───────┘

Print a camera snapshot

service: escpos_printer.print_camera_snapshot
data:
  source: camera.front_door
  cut: partial

Target a specific printer

service: escpos_printer.print_text
target:
  device_id: your_printer_device_id
data:
  text: "Sent to a specific printer"
  cut: partial

The services use Home Assistant's standard target picker, so you can target devices, entities, areas, floors, or labels — or set broadcast: true to print to every configured printer at once.
