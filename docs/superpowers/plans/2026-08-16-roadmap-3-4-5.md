# Roadmap items 3, 4, 5 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship ROADMAP items 3 (text styling `invert`/`density`/`font`), 4 (cover-open binary_sensor), and 5 (last-print timestamp sensor) for the 1.2.0 release.

**Architecture:** All three are additive. Item 3 threads three new optional fields through the existing schema → handler → adapter → `escpos.set()` path. Item 4 folds a DLE EOT n=2 query into the existing `get_paper_status()` connection (no second connection) plus a polled binary_sensor. Item 5 adds a `_last_print` field bumped only by print operations, plus a TIMESTAMP sensor.

**Tech Stack:** Python 3.14, Home Assistant custom integration, python-escpos 3.1, voluptuous, pytest (`uv run pytest -q`).

## Global Constraints

- Run tests with `uv run pytest -q` (unit suite; integration tests excluded by default). Lint: `uv run ruff check .`; types: `uv run mypy custom_components/`.
- `strings.json` and `translations/en.json` must stay **byte-identical**; the `services` key is generated from `services.yaml` by `python scripts/sync_service_translations.py`. Entity-name keys are hand-edited — edit both files identically.
- Every user-visible change gets a bullet under `## [Unreleased]` in CHANGELOG.md (folded into 1.2.0 at release time — do NOT edit the `## [1.2.0]` section).
- python-escpos `set()` sends **nothing** for a `None` param, and printer state is sticky across connections. Styling params must always be sent as concrete values (`invert=bool(...)`, `font=... or "a"`) — except `density`, which is deliberately sticky (hardware darkness knob) and passed through as-is (`None` → unchanged).
- Do not use `git stash` or `git reset`. Commit only the files you changed.
- Smallest diff that works; no speculative abstractions.

```python
async def get_cover_status(self, hass: HomeAssistant) -> bool | None:
```

```python
class EscposCoverOpenSensor(BinarySensorEntity):
    """Cover-open fault sensor via the ESC/POS DLE EOT n=2 query."""

    _attr_has_entity_name = True
    _attr_translation_key = "cover_open"
    _attr_device_class = BinarySensorDeviceClass.PROBLEM
    _attr_should_poll = True

    def __init__(self, entry: ConfigEntry) -> None:
        self._entry = entry
        self._attr_unique_id = f"{entry.entry_id}_cover_open"
        self._attr_available = False

    @property
    def device_info(self) -> DeviceInfo:
        return build_device_info(self._entry)

    async def async_update(self) -> None:
        runtime = getattr(self._entry, "runtime_data", None)
        adapter = getattr(runtime, "adapter", None) if runtime else None
        if adapter is None:
            self._attr_available = False
            self._attr_is_on = None
            return
        status = await adapter.get_cover_status(self.hass)
        if status is None:
            self._attr_available = False
            self._attr_is_on = None
            return
        self._attr_available = True
        self._attr_is_on = status
```

```python
class LastPrintSensor(SensorEntity):
    """Timestamp of the last successful print (text, QR, barcode, image, batch).

    Distinct from the Online sensor's last_ok, which status probes also
    refresh. Enables "no receipt printed today" automations. State is
    unknown until the first print after startup (the value is not
    persisted across restarts).
    """

    _attr_has_entity_name = True
    _attr_translation_key = "last_print"
    _attr_device_class = SensorDeviceClass.TIMESTAMP
    _attr_entity_category = EntityCategory.DIAGNOSTIC
    _attr_should_poll = True

    def __init__(self, entry: ConfigEntry) -> None:
        self._entry = entry
        self._attr_unique_id = f"{entry.entry_id}_last_print"

    @property
    def device_info(self) -> DeviceInfo:
        return build_device_info(self._entry)

    async def async_update(self) -> None:
        runtime = getattr(self._entry, "runtime_data", None)
        adapter = getattr(runtime, "adapter", None) if runtime else None
        if adapter is None:
            self._attr_available = False
            self._attr_native_value = None
            return
        self._attr_available = True
        self._attr_native_value = getattr(adapter, "_last_print", None)
```
(Enabled by default — unlike LastImagePrintSensor — because it's the automation hook this feature exists for; it reads memory, no I/O.)
